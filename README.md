## Задача 3

### Текст задачи

Имена.

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например "Иванов Иван Иванович"). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:

* Клеопатра
* Пушкин Александр Сергеевич
* Маяковский Владимир

Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения

Создается класс `Name`, в котором объявляются закрытые поля `firstName`, `lastName` и `patronymic`, а также свойства с проверкой на `null`.

После этого создается 5 конструкторов:

* первый конструктор по умолчанию, задаются базовые значения;
* второй конструктор с одним параметром, принимает только имя;
* третий конструктор с двумя параметрами, принимает имя и фамилию;
* четвертый конструктор с тремя параметрами, принимает имя, фамилию и отчество;
* пятый конструктор копирования, дублирует данные из переданного объекта.

Переопределяется метод `ToString()`: выполняется проверка каждого поля на `null` и непустую строку, после чего непустые поля объединяются через пробел, а лишний пробел в конце строки удаляется методом `Trim()`.

## Задача 4

### Текст задачи

Время.

Создайте сущность Время, которое будет описывать текущее время суток в 24-х часовом формате. Время описывается числом секунд, прошедшим с начала суток. Время может быть приведено к текстовой форме следующего формата: "ЧЧ:ММ:СС". Например, если время задано как 12000, то текстовая форма будет "3:20:00". Если общее время превышает 24 часа, то отображаться в текстовом виде должно только то время, которое прошло с начала последних суток, например 91800, это не 25:30:00, а 1:30:00.

Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени:

* 10 секунд
* 10000 секунд
* 100000 секунд

### Алгоритм решения

Создается класс `Time` с закрытым полем `totalSeconds` и свойством `TotalSeconds`. В блоке `set` вычисляется остаток от деления переданного числа на 86400 (количество секунд в сутках), что нормализует время в пределах одних суток и отбрасывает лишние дни.

Создаются конструкторы:

* первый конструктор по умолчанию, инициализирует секунды нулем;
* второй конструктор с одним параметром, принимает количество секунд с начала суток.

Переопределяется метод `ToString()`: вычисляются часы делением секунд на 3600, минуты — делением остатка от часа на 60, а секунды — остатком от деления на 60, после чего формируется и возвращается строка вида `ЧЧ:ММ:СС`.

# Задание 2

## Задача 4

### Текст задачи

Сотрудники и отделы.

Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причем у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: "Имя работает в отделе Название, начальник которого Имя". В случае если сотрудник является руководителем отдела, то текстовая форма должна быть "Имя начальник отдела Название".

Необходимо выполнить следующие задачи:

1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен оказаться один и тот же отдел и начальник).

### Алгоритм решения

Создается класс `Department` с полями названия отдела и начальника (типа `Employee`), а также конструкторами по умолчанию и с параметрами.

Создается класс `Employee` с закрытыми полями имени и отдела.

В классе `Employee` переопределяется метод `ToString()`:

* если текущий сотрудник совпадает с руководителем своего отдела (`Department.Manager == this`), формируется строка вида "Имя начальник отдела Название";
* иначе через ссылку на отдел извлекается имя начальника и возвращается строка "Имя работает в отделе Название, начальник которого Имя".

В методе `Main` создаются три объекта сотрудников с ссылкой на один общий отдел `IT`, после чего один из сотрудников назначается руководителем отдела.

# Задание 4

## Задача 4

### Текст задачи

Создаем Время.

Измените сущность Время из задачи 1.4. Новые требования включают:

* Время можно создать указав количество секунд с начала суток.
* Время можно создать указав количество часов, минут, секунд текущего времени.
* Гарантируйте, что операция присвоения в инициализаторах будет использована не более одного раза.

Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени:

1. 10000 секунд
2. 2 часа, 3 минуты, 5 секунд

### Алгоритм решения

В класс `Time` добавляется дополнительный конструктор с тремя параметрами: часы, минуты и секунды.

Для выполнения условия единственного присваивания в инициализаторах часы и минуты переводятся в общее число секунд по формуле `hours * 3600 + minutes * 60 + seconds`, после чего с помощью конструкции `: this(...)` вычисленное значение передается в основной конструктор по секундам, где и происходит единственная операция присваивания свойству `TotalSeconds`.

# Задание 5

## Задача 4

### Текст задачи

Сколько сейчас времени?

Измените сущность Время из задачи 4.4. Добавьте ей возможность возвращать следующие сведения:

* Какой сейчас час (целое число)
* Сколько минут прошло с начала текущего часа (целое число)
* Сколько секунд прошло с начала текущей минуты (целое число)

Необходимо выполнить следующие задачи:

1. Вывести на экран сколько часов соответствуют времени 34056
2. Вывести на экран сколько минут соответствуют времени 4532
3. Вывести на экран сколько секунд соответствуют времени 123

### Алгоритм решения

В класс `Time` добавляются три метода для извлечения составляющих времени:

* метод `GetHours()` выполняет целочисленное деление `totalSeconds / 3600` и возвращает текущий час;
* метод `GetMinutes()` берет остаток от часа `totalSeconds % 3600`, делит его на 60 и возвращает количество минут с начала часа;
* метод `GetSeconds()` берет остаток `totalSeconds % 60` и возвращает количество секунд с начала минуты.

В методе `Main` создаются объекты с заданным количеством секунд и демонстрируется вызов соответствующих методов.
